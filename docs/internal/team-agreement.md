## 3. Ownership and licence

1. The team owns the project. Each member co-owns the code they and the other member wrote, in equal shares unless both agree otherwise in writing.
2. The code is published under the licence in `LICENSE` (currently MIT). Changing the licence needs both members' written agreement.
3. The organizers receive the non-exclusive, royalty-free right to publish the team name, description, screenshots, photos and videos, as the rules state.
4. A pilot, incubation or government adoption would need a separate written agreement with all parties.

## 4. Rules both members promise to follow

- Use only team-created synthetic data, organizer-provided samples, or clearly public data.
- No real personal information, no scraping, no testing against live systems.
- List every AI tool used in the README (`docs/ai-tool-disclosure.md`).
- Keep the real Git history. Never squash it into one commit or delete commits.
- Never commit keys, passwords or `.env` files.

## 5. Decisions and deadlines

- Decisions are made together. If the members disagree on a technical point, the Team Leader decides, after hearing the other member's reasons.
- Internal deadlines follow the PRD plan. The Round 1 submission deadline is **16 October 2026**. Aim to submit hours early.
- If one member cannot continue, they tell the other and the organizers at once. Neither member takes the project's code or name away without the other's written consent.

## 6. Prize and credit
