# Round 1 submission checklist (deadline 18 October 2026)

Based on the PRD compliance checklist and the LandTech rule book. Re-check the event platform for rule changes before you submit.

## Deliverables
- [ ] Concept note PDF, **at most 3 pages** (`DagShield-Concept-Note.pdf`), names **P3** as the chosen problem and covers: problem, Bangladesh context, solution, architecture and stack, key features, countrywide plan, team and mentors (draft in `concept-note-draft.md`)
- [ ] **Public** GitHub repository link (rule book v1.2), with the real commit history
- [ ] README with setup, data and licence notes, and every AI tool used with a short note
- [ ] Demo video, **at most 90 seconds** (`demo-script.md`)
- [ ] Submitted on the LandTech Hackathon Platform **before 18 October 2026**, with hours to spare
- [ ] Every link opened from a logged-out browser or a private window

- [ ] Optional live link added: https://dagshield.newslensbd.com

## Rules
- [ ] Only synthetic, organizer-provided or clearly public data
- [ ] No real personal data or private land records in the repo, demo, screenshots or video
- [ ] No scraping, automated querying or bulk download from government portals
- [ ] No security testing against live government or third-party systems
- [ ] Git history is real and not squashed
- [ ] Both students can explain the code and design
- [ ] No keys or passwords in Git (`python scripts/check_secrets.py` passes)

## Paperwork
- [ ] Registration confirmation and BDT 200 fee receipt saved
- [ ] Team agreement signed by both members (`team-agreement.md`)
- [ ] `LICENSE` confirmed and `THIRD_PARTY_LICENSES.md` checked
- [ ] AI tool disclosure edited to be accurate
- [ ] Mentor names and agreement confirmed (assigned by the organizers)
- [ ] Organizer replies saved (`organizer-queries.md`)

## If you reach the final round
- [ ] BDT 100 confirmation fee paid within 3 days of the announcement; receipt saved
- [ ] Updated code link and pitch deck PDF (max 10 slides) uploaded before presenting
- [ ] README lists the changes made since Round 1
- [ ] Laptop, charger, offline-ready demo, Participant ID card or registration confirmation
